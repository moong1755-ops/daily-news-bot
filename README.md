# Impact VC Daily News Bot

임팩트 VC 투자심사역이 매일 아침 5분 안에 시장의 중요한 변화를 파악할 수 있도록 돕는 AI 뉴스 브리핑 봇입니다.

이 프로젝트의 목표는 기사를 많이 보내는 것이 아닙니다. 투자 판단에 도움이 되는 기사만 남기고, 같은 사건의 반복 보도와 홍보성 콘텐츠를 줄이는 것이 목표입니다.

> Quality over Quantity. 기사 수를 억지로 채우지 않습니다.

## 현재 운영 상태

- GitHub Actions에서 실행됩니다.
- 현재 외부 예약 서비스가 매일 오전 7시 25분경 GitHub의 수동 실행 기능을 호출합니다.
- RSS, 공식 홈페이지, Google News, Gmail 뉴스레터를 함께 사용합니다.
- Gemini가 임팩트 VC 편집장 역할로 기사 자격과 우선순위를 판단합니다.
- 최종 결과는 Slack Block Kit 메시지 한 건으로 발송합니다.
- 자동 테스트 100개가 기사 분류, 중복 제거, 지역별 개수와 출력 형식을 검사합니다.

최근 통합 미리보기는 정상 완료됐지만, 일부 거시경제 오분류와 카테고리 간 중복, 긴 실행시간은 계속 개선 중입니다. 자세한 내용은 [현재 확인 중인 개선 항목](#현재-확인-중인-개선-항목)을 참고하세요.

## 편집 원칙

### 독자

일반 독자가 아니라 임팩트 VC 투자심사역을 위한 브리핑입니다.

### 우선순위

1. 정책·규제 변화와 시장 구조 변화
2. 투자, 펀드 결성, M&A, IPO와 회수
3. 대형 계약과 공공조달
4. 핵심 기업의 전략 변화와 검증된 기술 혁신
5. 파산, 제재, 소송, 그린워싱 등 투자 위험
6. 실증 결과, 임팩트 측정과 검증된 사회·환경 성과

### 임팩트는 필수 분야

다음 분야를 임팩트로 봅니다.

- 기후테크·에너지전환
- 사회적경제·소셜벤처
- ESG
- 돌봄
- 헬스케어
- 교육
- 금융포용
- 순환경제

기사의 투자금액만 보지 않습니다. 해결하는 문제의 크기, 추가성, 확장성, 정책 연계, 공공조달, 실증과 성과 검증도 함께 판단합니다.

### 제외 대상

- 채용공고와 구인글
- 행사·웨비나·시상식 참가 안내
- 단순 인터뷰·인물 프로필·팟캐스트
- 사설·칼럼·오피니언
- 홍보기사·광고·스폰서 콘텐츠
- 지자체 지원사업 신청 안내와 단순 업무협약
- 종목 추천과 주가 전망
- 주간 경제일정과 헤드라인 단순 모음
- 기사 목록·검색 결과·회사 소개 페이지
- 회계기준 시행일과 세무 알림 등 단순 실무 공지
- 출처와 취재 근거가 불분명한 소문

신뢰할 수 있는 매체가 구체적으로 보도한 대형 인수 협상, 투자 검토, 규제 가능성, 시장 전망은 시장 신호로 남길 수 있습니다. 다만 협상·검토·전망을 확정 사실처럼 표현하지 않습니다.

## 고정 카테고리와 기사 수

| 카테고리 | 기본 출력 | 운영 원칙 |
|---|---:|---|
| 🌱 임팩트 | 최대 3개 | 중요한 필수 사건은 최대 5개까지 허용 |
| 🤖 AI | 최대 3개 | 투자·규제·계약·상용화·기술 검증 중심 |
| 📈 대체투자 | 해외 3개 + 국내 3개 | 해외 먼저 표시, 확정 주요 딜 중심 |
| 🌐 거시·정책·지정학 | 해외 3개 + 국내 3개 | 해외 먼저 표시, 핵심 시장 중심 |
| 👔 MBB·Big4 인사이트 | 최대 3개 | 공식 리포트·전망·트렌드·이슈 브리프 중심 |

선택할 가치가 있는 기사가 없으면 다음 문구를 표시합니다.

```text
오늘 조건에 맞는 뉴스가 없습니다.
```

임팩트 기사에 다른 신뢰 출처가 있으면 한 언론사가 지면을 독점하지 않게 합니다. 다른 출처가 전혀 없을 때는 출처 제한 때문에 임팩트 기사가 2개에서 멈추지 않도록 다음 우수 기사를 허용합니다.

## 거시경제 범위

기본 관찰 국가는 다음과 같습니다.

- 미국
- 유럽 주요국과 유로존
- 중국
- 일본
- 한국

그 밖의 국가는 세계 금융시장, 원유·에너지, 공급망, 무역로, 전쟁과 제재에 파급되는 사건만 예외적으로 다룹니다. 한 국가 안에서 끝나는 일반 금리 변경이나 현지 주가 반응은 원칙적으로 제외합니다.

## 뉴스 수집 전략

수집 우선순위는 다음과 같습니다.

```text
검증된 원문 RSS·공식 홈페이지
        ↓
Google News 보완 검색
        ↓
Gmail 뉴스레터 링크
```

- 해외 원문을 우선합니다.
- 국내 매체는 국내 시장과 정책, 국내 투자 딜을 보완합니다.
- 카테고리별 출처와 검색어는 [`src/config.py`](src/config.py)에서 관리합니다.
- 새로운 RSS나 공식 페이지는 가능한 한 `config.py`만 수정해서 추가합니다.
- 죽은 RSS와 반복적으로 실패하는 출처는 제거하거나 보완 경로를 둡니다.

주요 출처에는 Impact Alpha, ImpactOn, ESG Today, Pioneers Post, TechCrunch, VentureBeat, PE Hub, Bloomberg, Reuters, 한경 마켓인사이트, 딜사이트, 플래텀, 벤처스퀘어와 MBB·Big4 공식 사이트 등이 포함됩니다. 실제 활성 출처 목록은 항상 `src/config.py`가 기준입니다.

## 처리 흐름

```text
RSS·공식 페이지·Google News·Gmail 수집
                    ↓
URL·과거 발송·당일 동일 사건 중복 제거
                    ↓
기사 자격 판정과 카테고리 분류
                    ↓
Gemini 임팩트 VC 편집 게이트
                    ↓
과거 발송 기사와 의미 중복 제거
                    ↓
선별 후보 제목 번역
                    ↓
카테고리별 개수·지역·출처 다양성 적용
                    ↓
Slack 한 메시지 발송
                    ↓
실제 발송 기사만 seen 기록
```

같은 회사가 등장해도 투자, 인수, 규제, 소송처럼 사건이 다르면 별도 기사로 남깁니다. 같은 사건을 여러 언론사가 보도하면 원문성과 출처 신뢰도가 높은 대표 기사 하나를 우선합니다.

## GitHub에서 실행하는 방법

코딩을 몰라도 GitHub 화면에서 실행할 수 있습니다.

1. 저장소의 **Actions** 탭을 엽니다.
2. 왼쪽에서 **News Bot 📰**을 선택합니다.
3. **Run workflow** 버튼을 누릅니다.
4. 실행 방식을 선택합니다.

| 입력 항목 | 설명 |
|---|---|
| `dry_run` | 켜면 Slack 발송과 seen 저장 없이 최종 결과만 확인 |
| `editor_gate` | Gemini 편집 게이트 사용. 기본값은 켜짐 |
| `as_of_date` | `YYYY-MM-DD` 형식으로 과거 날짜를 일부 재현 |

새 코드를 확인할 때는 반드시 `dry_run`을 먼저 켜는 것을 권장합니다.

## GitHub 비밀 설정

저장소의 **Settings → Secrets and variables → Actions**에서 설정합니다.

### 필수

| 이름 | 역할 |
|---|---|
| `SLACK_WEBHOOK_URL` | 실제 Slack 채널 발송 주소 |
| `GEMINI_API_KEY` | 기사 자격 판정·선별·번역 |

`dry_run`에서는 Slack 주소가 없어도 되지만 Gemini 키는 필요합니다.

### Gmail 뉴스레터 사용 시 한 쌍으로 필요

| 이름 | 역할 |
|---|---|
| `GMAIL_USER` | 뉴스레터를 받는 Gmail 주소 |
| `GMAIL_APP_PASSWORD` | Gmail 앱 비밀번호 |

둘 중 하나만 설정하면 실행이 중단됩니다. 둘 다 없으면 RSS만 수집합니다.

### 선택

| 이름 | 역할 |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Telegram 보조 발송 봇 토큰 |
| `TELEGRAM_CHAT_ID` | Telegram 발송 대상 |

저장소 변수 `GEMINI_MODEL`로 모델을 지정할 수 있습니다. 비우면 코드의 기본 후보와 자동 탐색 기능을 사용합니다.

## Gmail 보안과 개인정보

- Gmail은 IMAP 읽기 전용으로 접근합니다.
- Gmail 계정 비밀번호 대신 Google 앱 비밀번호를 사용합니다.
- 뉴스레터 메일에서 기사 링크를 추출합니다.
- 선별 과정에서 기사 제목, 요약, 출처, 사건 상태 등의 정보가 Gemini API로 전송될 수 있습니다.
- 일반 회사 메일이나 개인 대화가 섞이지 않도록 전용 Gmail 라벨과 검색조건을 사용하는 것을 권장합니다.
- 비밀값은 GitHub Secrets에만 저장하고 코드나 README에 직접 적지 않습니다.

기본 검색조건은 `label:newsletters`, 최근 3일, 최대 20개 메일, 메일당 최대 8개 링크입니다. 필요한 경우 다음 환경변수로 조절할 수 있습니다.

- `GMAIL_NEWSLETTER_QUERY`
- `GMAIL_IMAP_FOLDER`
- `GMAIL_LOOKBACK_DAYS`
- `GMAIL_MAX_EMAILS`
- `GMAIL_LINKS_PER_EMAIL`

## 컴퓨터에서 미리보기 실행

Windows PowerShell 기준입니다.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

$env:GEMINI_API_KEY="본인의 키"
$env:DRY_RUN="1"

```

`DRY_RUN=1`이면 Slack으로 보내지 않고 seen 기록도 바꾸지 않습니다. 비밀값이 터미널 기록에 남을 수 있으므로 공용 컴퓨터에서는 직접 입력하지 마세요.

현재 자동 테스트는 다음을 포함합니다.

- 임팩트 우선 분류
- 확정 딜과 루머 구분
- 정책·투자·라운드별 사건 중복 보호

- Gemini 장애 시 안전한 대체 경로

## 데이터와 중복 기록

- `data/seen_news.txt`: 이미 발송한 링크
- `data/seen_titles.txt`: 이미 발송한 제목
- `data/seen_embeddings.npz`: 날짜가 달라도 같은 사건인지 비교하는 상태
- `data/slack_archive.jsonl`: 실제 발송한 Slack 본문 기록
- `data/last_run_decisions.json`: 최근 실행의 기사별 판정 기록

실제로 Slack 발송에 성공한 기사만 seen 상태에 저장합니다. 선택되지 않은 좋은 기사가 다음 날 다시 후보가 될 수 있도록 미발송 기사는 seen에 넣지 않습니다.

## 장애 시 동작

- 일부 RSS가 실패해도 다른 출처 수집은 계속합니다.
- 공식 RSS가 죽으면 설정된 경우 Google News 보완 검색을 사용합니다.
- Gemini가 실패하면 규칙 기반 상대 순위로 전환합니다.
- 번역이 실패하면 제목을 자르지 않고 원문 제목을 유지합니다.
- Slack 발송이 실패하면 해당 기사를 발송 완료로 기록하지 않습니다.
- GitHub 테스트는 최대 20분, 뉴스봇은 최대 35분 후 자동 종료됩니다.

## 현재 확인 중인 개선 항목

2026년 8월 24일 통합 미리보기에서 다음을 확인했습니다.

- 100개 자동 테스트 통과
- Gmail 최근 메일 4건에서 기사 링크 32건 수집
- 최종 미리보기 23건 생성
- 대체투자와 거시경제의 해외 3개 + 국내 3개 형식 정상
- Slack 발송과 seen 저장 없이 안전하게 종료

아래 항목은 추가 개선이 필요합니다.

- 비핵심 국가의 지역 금리 기사가 거시에 남는 문제
- 회계 공지와 주간 경제일정이 거시에 남는 문제
- 같은 사건이 AI와 대체투자에 한 번씩 나타나는 카테고리 간 중복
- 최종 23개를 고르기 전에 너무 많은 제목을 번역하는 비효율
- Gemini 자동 탐색이 이미지·음성 모델까지 시도하는 문제
- McKinsey Korea 페이지의 간헐적 시간 초과
- 한경 마켓인사이트 직접 페이지의 403 차단
- 통합 실행시간 약 18분

실제 발송 전에는 `dry_run` 결과를 먼저 검토합니다.

## 주간 브리핑 로드맵

주간 브리핑은 아직 구현되지 않았습니다. 일간 뉴스 5일치를 그대로 붙이지 않고, 같은 사건의 후속보도를 하나로 합쳐 투자 판단에 중요한 변화만 전달할 계획입니다.

추천 발송 시간은 월요일 오전입니다.

계획 중인 구성은 다음과 같습니다.

- 이번 주 핵심 변화 5줄
- 임팩트 필수 이슈 3~5개
- AI 핵심 변화 2~3개
- 국내외 주요 투자·M&A·회수 5~6개
- 거시·정책 변화 3~4개
- MBB·Big4 주요 리포트 2~3개
- 다음 주 확인할 이슈 3개
- 시장 지표판

시장 지표판은 KOSPI, KOSDAQ, 원/달러 환율, S&P 500, Nasdaq, 미국 10년물 금리, Brent 유가 등을 후보로 검토합니다. 단순 현재값보다 금요일 기준값, 주간 변화와 VC 관점의 짧은 해석을 함께 보여주는 방향입니다.

시장 수치는 LLM이 만들지 않고 검증된 데이터 소스에서 가져옵니다. 공식 데이터 제공처와 사용 조건을 확인한 뒤 별도 수집 모듈로 구현할 예정입니다.

## 개발 원칙

- 새로운 RSS와 카테고리는 가능한 한 `config.py`에서 관리합니다.
- 함수는 작게 유지하고 파일 역할을 분리합니다.
- 한 번에 한 파일씩 수정하고 자동 테스트로 확인합니다.
- 새로운 LLM으로 교체할 때 선별 로직 전체를 다시 만들지 않도록 인터페이스를 분리합니다.
- Slack 외 이메일·Notion·Discord 등 출력 채널을 추가할 수 있는 구조를 지향합니다.
- 발송량보다 투자 의사결정에 도움이 되는 품질을 우선합니다.
